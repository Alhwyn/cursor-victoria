# Cursor Codechella

Landing page for **Cursor Codechella @ Victoria, BC** — a one-day hackathon styled after [Cursor Compile](https://cursor.com/compile) and Cursor brand guidelines.

## Develop

```bash
bun install
bun dev
```

## Production

```bash
bun run build
bun start
```
